# Dark Mode Toggle Project

This is a simple project that allows users to switch between Light and Dark modes using JavaScript DOM manipulation.

## Technologies Used
- HTML
- CSS
- JavaScript (DOM)

## Features
- Toggle button to switch themes
- Uses `classList.toggle()` to apply dark mode
- Responsive and beginner-friendly
